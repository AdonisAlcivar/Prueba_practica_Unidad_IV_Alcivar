# Prueba_practica_Unidad_IV_Alcivar


### Ingeniería de Requisitos — Caso: Sistema de Gestión de Pedidos

Este repositorio contiene el desarrollo en LaTeX de las actividades *P1 a P10* correspondientes a la Prueba Práctica de la Unidad IV de la asignatura ISR-401. El proyecto incluye los diagramas UML de clases, actividades y máquina de estados, elaborados utilizando *TikZ* y *Visual Paradigm*.

```text

├── main.tex                                      # Documento principal en LaTeX
├── diagramas/

│   └── readme.md                                 # Información de la carpeta
├── figuras_diagramas/
